# Table files

Upload the four `TableN_*.docx` files using PeerJ's **Table** designation.
They are editable US Letter primary files with visible cell borders.

The matching PDFs are review copies. `Tables.docx` is a combined convenience
copy and is not a primary upload file. The Table 4 EPS file is a compatibility
derivative created after the portal assigned the wrong vector-artwork file
type. Do not use it when a Table upload row is available.

See `../UPLOAD_MAP.md` for the authoritative upload list.
