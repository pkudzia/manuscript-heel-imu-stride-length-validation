# Screening-group metadata

`participant_groups.csv` transcribes the 32 analysed participants from Supplementary Table S1. It contains only anonymized study codes, MoCA totals and the reported CN/CI screening labels. ID_139 uses the author-corrected total of 27. The excluded participant is not listed. This table supports cognitive-group analysis and contains no source identifiers or linkage information.

Rows retain Table S1 order. This preserves the original participant ordering for fixed-seed bootstrap draws after identifiers were anonymized. Numeric ID sorting would change the Monte Carlo intervals.
